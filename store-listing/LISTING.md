# Rave AI, development listing draft

App name: **Rave AI**

Rave AI records microphone audio on a Wear OS watch, saves it locally, and uploads finalized recordings to the user's Google Drive after linking an account. Recordings use approximately one-minute WAV segments, including silence. Local cleanup requires a verified matching cloud copy.

This branch is under development. Physical Pixel Watch 5 qualification and battery measurements are pending. After reboot, the user must open the app to resume microphone capture. Uploads may use metered connections.

No transcription or AI memory processing is included in the current recorder milestone. See [README.md](../README.md) and [PRIVACY.md](../PRIVACY.md) for current behavior and limitations.
